# 🟫 Minecraft Clone

A simple browser-based Minecraft-like voxel game built with Three.js. No installation needed — just open `index.html` in your browser!

## 🎮 Controls

| Key | Action |
|-----|--------|
| `WASD` | Move |
| `Space` | Jump |
| `Mouse` | Look around |
| `Left Click` | Break block |
| `Right Click` | Place block |
| `1–6` | Select block type |

## 🧱 Block Types

1. Grass
2. Dirt
3. Stone
4. Wood
5. Sand
6. Leaves

## 🚀 How to Run

1. Clone this repo:
   ```bash
   git clone https://github.com/YOUR_USERNAME/minecraft-clone.git
   ```
2. Open `index.html` in your browser — that's it!

> No build tools, no npm, no dependencies to install. Three.js is loaded from a CDN.

## 🌐 Play Online (GitHub Pages)

You can host this for free on GitHub Pages:

1. Go to your repo → **Settings** → **Pages**
2. Under **Branch**, select `main` and folder `/root`
3. Click **Save**
4. Your game will be live at: `https://YOUR_USERNAME.github.io/minecraft-clone`

## 🛠️ Built With

- [Three.js r128](https://threejs.org/) — 3D rendering
- Vanilla JavaScript — game logic
- HTML5 Canvas + Pointer Lock API — input handling
